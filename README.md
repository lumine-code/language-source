# language-source

Base source file support.

Fork of [pulsar-edit/pulsar](https://github.com/pulsar-edit/pulsar) (`packages/language-source`).

## Features

- **Grammars**: provides none. This package is scoped settings only, maintained here rather than derived from an upstream grammar.
- **Comment toggling**: provides fallback comment patterns shared by all source files.

## Installation

To install `language-source` search for it in the Install pane of the Lumine settings, or run the command `lumine --install lumine-code/language-source`.
